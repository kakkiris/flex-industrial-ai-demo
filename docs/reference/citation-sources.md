# Citation Sources

Quick-lookup legend for the citation tags used across `process.md` files and specs. The underlying sources (interview recordings, questionnaires, and client-delivered files) are confidential engagement materials and are **not included in this repository**. The tags are kept so each "current process" claim stays traceable to the conversation or artifact it came from.

| Citation tag | Source type |
| --- | --- |
| `[Discovery-Jordan HH:MM:SS]` | Discovery interview with the platform lead (Jordan Reyes, fictional name), timestamped |
| `[Discovery-Alex HH:MM:SS]` | Discovery interview with the portfolio manager / analyst (Alex Chen, fictional name), timestamped |
| `[Pre-discovery-Jordan]` | Pre-discovery questionnaire response, platform lead |
| `[Pre-discovery-Alex]` | Pre-discovery questionnaire response, portfolio manager |
| `[Kick-off HH:MM:SS]` | Kick-off / business-context meeting, timestamped |
| `[Validation 2026-06-04]` | Demo + validation session with the client |
| `[Cold call notes]` | Client-delivered cold call notes (A2 script source) |
| `[Pre-audit]` | Client's pre-audit list of AI initiatives |
| `[Rent roll structure]` | Client-delivered rent roll data-structure workbook (54 columns) |

The layout rules for where source materials live relative to the repo are in `docs/reference/file-layout-deep.md`.
